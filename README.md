# AWS Student Builder Group at EPN · Eventos

Sitio de planificación y materiales para los eventos del AWS Student Builder Group at EPN.

## Estructura

- `/index.html` — hub general de eventos.
- `/eventos/evento-01/` — Tu primer servidor en la nube.
- `/eventos/evento-02/` — Cloud Security Basics.
- `/eventos/evento-03/` — Serverless Sprint.
- `/eventos/evento-04/` — AI Builder Night.
- `/eventos/evento-05/` — Cloud Defense Challenge.
- `/eventos/evento-06/` — EPN Buildathon.
- `/assets/styles.css` — estilos compartidos.
- `/assets/merch/` — biblioteca prevista para los assets visuales compartidos por el grupo.

Cada evento tendrá su propia vista siguiendo una plantilla común: objetivo, fundamentos, agenda, guion, práctica, checkpoints, roles, prerrequisitos, copy para Meetup/LinkedIn y checklist operativo.

## Evento 1

**Tu primer servidor en la nube** cubre cloud computing, regiones, Availability Zones, IAM, MFA, costos, buenas prácticas, EC2, Security Groups, Nginx, Cloud Gallery y limpieza de recursos.
