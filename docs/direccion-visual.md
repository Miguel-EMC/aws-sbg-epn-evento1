## Lenguaje visual extraído

- Azul marino como color estructural principal.
- Fondos crema/papel tomados de tote bags y welcome kits.
- Naranja AWS como acento de acción.
- Cyan/azul claro EPN como segundo acento.
- Variantes vino y verde como paleta secundaria.
- Bordes tipo parche/badge y sensación de merch bordado.
- Cards limpias, redondeadas y con detalles de “stitch”.
- Identidad EPN + Student Builder Group presentada como una comunidad estudiantil.

## Arquitectura web

Cada evento tiene una vista propia en `/eventos/evento-XX/` y comparte el sistema visual de `/assets/styles.css`.
